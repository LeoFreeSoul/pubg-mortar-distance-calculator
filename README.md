# PUBG 迫击炮测距（简体中文版）

这是 [reallav0/pubg-mortar-distance-calculator](https://github.com/reallav0/pubg-mortar-distance-calculator) 的中文界面版本。程序在屏幕上显示一个透明覆盖层，供你在 PUBG 地图上依次点击炮位和目标，再按地图比例尺估算两点间距离。程序不读取游戏数据。

## 使用方法

1. 以正常分辨率运行 PUBG，打开地图并调整到准备测距的缩放级别。原项目注明支持无边框／全屏模式，不支持拉伸分辨率。
2. 按 `Alt+Y` 或点击「校准 100 米」，在地图上点击同一个 100 米小格**一条水平或竖直边的两端**。轻微点歪会自动按横向或纵向对齐；偏斜太多会提示重试。不要点对角线，因为对角线约为 141 米。窗口会显示「100 米 = 多少像素」。
3. 校准成功后，默认按 `Y` 开始测距。可在主窗口修改测距快捷键，点击「设置」。
4. 在覆盖层上先点击迫击炮位置，再点击目标位置。按 `Esc` 可取消。测距结果会在游戏画面上短暂显示，也会留在主窗口。

校准一次后可连续测距，不需要每次重校。点击「清除校准」、开始重新校准或重启程序后，旧比例失效，必须重新校准才能测距。程序无法自动检测换图或地图缩放变化；发生变化时请主动按 `Alt+Y` 重新校准。结果仅供游戏内参考；目标标点或校准点不准会造成误差。实际落点还需根据地形高差和首发炮弹修正。

## 从源码运行

需要 Node.js 和 npm：

```powershell
npm install
npm start
```

## 打包 Windows 便携版

```powershell
npm run dist
```

生成的 EXE 位于 `dist` 文件夹。最小化主窗口后，它会留在系统托盘；可在托盘菜单中显示、隐藏或退出。

## 计算方式

```text
像素距离 = √((x₂ - x₁)² + (y₂ - y₁)²)
游戏距离（米） = 像素距离 ÷ 每 100 米像素数 × 100
```
