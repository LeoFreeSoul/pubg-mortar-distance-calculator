# PUBG 迫击炮测距（简体中文版）

这是 [reallav0/pubg-mortar-distance-calculator](https://github.com/reallav0/pubg-mortar-distance-calculator) 的中文界面版本。程序在屏幕上显示一个透明覆盖层，供你在 PUBG 地图上依次点击炮位和目标，再按地图比例尺估算两点间距离。程序不读取游戏数据。

## 使用方法

1. 以正常分辨率运行 PUBG，打开地图，在程序中选择当前地图，并调整到准备测距的缩放级别。原项目注明支持无边框／全屏模式，不支持拉伸分辨率。
2. 按 `Alt+Y` 或点击「校准 100 米」，在地图上点击同一个 100 米小格**一条边的两端**。不要点对角线，因为对角线约为 141 米。窗口会显示「100 米 = 多少像素」；校准只在本次运行中保留。
3. 默认按 `Y` 开始测距。可在主窗口修改快捷键，点击「设置」。
4. 在覆盖层上先点击迫击炮位置，再点击目标位置。按 `Esc` 可取消，主窗口会显示估算距离。

切换地图会清除本次手动校准，并按所选地图重新估算比例尺；再次点击「恢复自动」也使用当前所选地图。自动比例以原项目的 8×8 公里地图、屏幕分辨率数据为基准，按 `8 ÷ 所选地图边长（公里）` 换算。这是比例估算，仅适用于地图最大缩放，尚未逐张地图在游戏内验证。改变地图缩放后请重新校准。结果仅供游戏内参考；目标标点或校准点不准会造成误差。实际落点还需根据地形高差和首发炮弹修正。

## 从源码运行

需要 Node.js 和 npm：

```powershell
npm install
npm start
```

## 打包 Windows 便携版

```powershell
npm run dist
```

生成的 EXE 位于 `dist` 文件夹。最小化主窗口后，它会留在系统托盘；可在托盘菜单中显示、隐藏或退出。

## 计算方式

```text
像素距离 = √((x₂ - x₁)² + (y₂ - y₁)²)
游戏距离（米） = 像素距离 ÷ 每 100 米像素数 × 100
```
